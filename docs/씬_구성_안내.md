# 노트북에서 하는 일 — A to Z

씬·UI·프로젝트 설정까지 전부 저장소에 들어 있다. 에디터에서 **만들 것은 없다.**
설치 → 받기 → 열기 → Play → 빌드 순서로 끝난다.

---

## 1. 설치 (한 번만)

1. **Git**: https://git-scm.com/download/win → 전부 기본값으로 Next
2. **Unity Hub**: https://unity.com/download → 설치 후 로그인 (개인 무료 라이선스)
3. Hub → `Installs` → `Install Editor` → **2022.3 LTS** (아무 패치 버전이나 됨)
   - 모듈: `Windows Build Support (IL2CPP)` 는 필요 없음. 기본(Mono)이면 됨
   - `Microsoft Visual Studio Community` 는 있으면 편하지만 없어도 됨

## 2. 받기

원하는 폴더(예: `C:\Unity`)에서 우클릭 → `Open Git Bash here`:

```
git clone -b claude/annyeong-m6eeaa https://github.com/sihoo101209-ctrl/game_projcet
```

`C:\Unity\game_projcet` 폴더가 생긴다. 이게 Unity 프로젝트 폴더다.

## 3. 열기

- Hub → `Projects` → `Add` → `C:\Unity\game_projcet` 선택 → 목록에서 클릭
- "다른 버전으로 열겠냐" 물어보면 설치한 2022.3 선택
- 처음 열 때 패키지 받느라 1~3분 걸림
- 열리면 하단 `Console` 탭 확인 — **빨간 에러가 있으면 그대로 복사해서 보내기**

## 4. Play

- `Project` 창 → `Assets/Scenes/Start` 더블클릭 → ▶
- 기기 번호 `1`, 참가자 번호 `1` 입력 → 시작 (Enter 도 됨)
- Game 씬으로 넘어가면 성공. WASD 이동 · 마우스 꾹 눌러 공격 · ESC 메뉴
- 콘솔에 `[맵 A] 총 적 수 = 20 ✓` 확인
- 우하단 `ver. A` 확인

Game 씬만 바로 Play 해도 된다 (기기 0 / 참가자 0 테스트 세션으로 돌아감).

## 5. 빌드

### A 빌드
1. `Assets/Scenes/Start` 열기 → Hierarchy 에서 `GameLogger` 클릭 → Inspector `Map Version` 이 **A** 인지 확인
2. `File → Build Settings` → 씬 목록에 Start / Game 이 이미 있음 → `Build`
3. 새 폴더 `Build_A` 만들어 선택
4. `Build_A\game_projcet.exe` 실행 → 한 판 → 종료 → `Build_A\logs\summary.csv` 열어 `버전` 열 = `A` 확인

### B 빌드
1. Start 씬 `GameLogger` → `Map Version` 을 **B** 로 → `Ctrl+S`
2. Build → 새 폴더 `Build_B`
3. 실행 → `ver. B` 확인 → 방 3에서 위로 올라가 복도 확인 → 102에서 아래로 떨어지면 방 2 인지 확인
4. `Build_B\logs\summary.csv` → `버전` = `B`, `되돌림복도진입` = `O`

### USB
`Build_A`, `Build_B` 폴더 통째로 복사. 로그는 각 폴더의 `logs\` 에 쌓인다.

## 고치고 싶을 때

에러·스크린샷을 보내면 수정해서 같은 브랜치에 푸시한다. 노트북에서는:

```
cd C:\Unity\game_projcet
git pull
```

Unity 로 돌아가면 자동으로 다시 컴파일된다.

## 참고: 씬 구성

| 씬 | 오브젝트 | 역할 |
|---|---|---|
| Start | `GameLogger` | 로그 수집 + **Map Version (A/B)** — 빌드 직전 확인 |
| Start | `TitleScreen` | 타이틀 UI 를 코드로 생성 (기기/참가자 입력, 안내, ver. 표시) |
| Game | `MapBuilder` | JSON 읽어 방·문·적·플레이어·UI 전부 생성 |

카메라·UI·프리팹은 전부 코드가 만든다. 예쁜 프리팹을 만들면 `MapBuilder` 의 프리팹 슬롯에 꽂으면 교체된다.

## 자동 생성 색상

| 대상 | 색 |
|---|---|
| 플레이어 | 하늘색 |
| 근접 / 원거리 / 탱커 | 빨강 / 주황 / 어두운 빨강(큼) |
| 준보스 / 보스 | 보라 (더 큼) |
| 잠긴 문 / 열린 문 | 빨강 / 초록(반투명) |
