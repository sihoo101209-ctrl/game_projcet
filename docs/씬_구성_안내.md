# 씬 구성 안내 — 에디터에서 할 일

코드는 전부 저장소에 있다. Unity 에디터에서는 아래만 하면 플레이 가능하다.
**프리팹은 하나도 안 만들어도 된다** — 슬롯을 비워두면 색깔 사각형으로 자동 생성된다.
(나중에 예쁜 프리팹을 만들면 MapBuilder 슬롯에 꽂기만 하면 교체됨)

## 0. 프로젝트 준비

1. Unity 2D 프로젝트에 이 저장소 내용을 그대로 배치 (`Assets/Scripts`, `Assets/Resources`)
2. TextMeshPro 임포트 (타이틀 화면 입력 필드용): Window → TextMeshPro → Import TMP Essential Resources
3. Edit → Project Settings → Physics 2D → Gravity Y = 0 (아니어도 코드가 개별 처리하지만 안전하게)

## 1. Game 씬 (이름: `Game`)

| 오브젝트 | 컴포넌트 |
|---|---|
| Main Camera (기본) | 그대로 둠 (카메라 설정은 코드가 함) |
| 빈 오브젝트 `MapBuilder` | `MapBuilder` 스크립트 |

끝. 나머지(방·문·적·플레이어·UI 전부)는 실행 시 자동 생성된다.
에디터에서 Game 씬만 바로 Play 해도 테스트 세션(기기 0/참가자 0)으로 돌아간다.

## 2. Start 씬 (이름: `Start`)

CLAUDE.md 의 타이틀 화면 레이아웃대로 uGUI + TMP 로 구성:

| 오브젝트 | 컴포넌트 / 연결 |
|---|---|
| 빈 오브젝트 `GameLogger` | `GameLogger` 스크립트 — **빌드 직전 Map Version 을 A 또는 B 로!** |
| Canvas 안 제목 텍스트 2줄 | "게임 프로젝트 / 레벨 배치 테스트" |
| TMP_InputField `기기 번호` | |
| TMP_InputField `참가자 번호` | |
| 경고용 TMP_Text (선택) | |
| 버튼 `시작` | OnClick → `SessionStartUI.OnStartButton` |
| 빈 오브젝트 `SessionStartUI` | `SessionStartUI` — 위 필드들 연결, gameSceneName = `Game` |
| 우하단 작은 TMP_Text | `VersionLabel` 스크립트 부착 (ver. A/B 자동 표시) |
| 안내 텍스트 | "WASD 이동 · 마우스 클릭 공격 / 방의 적을 모두 처치하면 문이 열립니다 / ESC 를 누르면 메뉴가 열립니다" |

## 3. Build Settings

- Scenes In Build: `Start` (0번), `Game` (1번)
- Player 설정: Fullscreen Mode = Windowed, 1280×720 (코드도 강제하지만 이중 안전)
- Resizable Window 끄기 권장

## 4. 빌드 직전 체크 (데이터 무효 방지)

1. Start 씬 GameLogger 의 **Map Version 확인** (A 빌드 = "A", B 빌드 = "B")
2. Play 후 콘솔에 `[맵 X] 총 적 수 = 20 ✓` 확인
3. 타이틀 우하단 `ver. X` 가 의도한 버전인지 확인
4. 로그 위치: 빌드 = exe 옆 `logs/`, 에디터 = persistentDataPath

## 자동 생성 시 색상 안내

| 대상 | 색 |
|---|---|
| 플레이어 | 하늘색 |
| 근접 | 빨강 |
| 원거리 | 주황 |
| 탱커 | 어두운 빨강 (크다) |
| 준보스/보스 | 보라 (더 크다) |
| 잠긴 문 | 빨강 / 열린 문 | 초록(반투명) |
