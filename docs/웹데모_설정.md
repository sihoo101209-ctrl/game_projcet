# 웹 데모 — GitHub Pages 에서 플레이하기

목적: 설치 없이 링크 하나로 게임을 보여주기 위한 **데모 전용**.
본 실험은 여전히 USB exe 로 진행한다 (브라우저는 창 크기·로그 저장을 통제할 수 없음).

배포 주소 (설정 완료 후): **https://sihoo101209-ctrl.github.io/game_projcet/**

## 한 번만 하는 설정 (약 10분)

### 1. Unity 라이선스 파일 확보

노트북에 Unity Hub 를 설치하고 로그인하면 개인 라이선스가 자동 활성화되고, 이 파일이 생긴다:

```
C:\ProgramData\Unity\Unity_lic.ulf
```

(`ProgramData` 는 숨김 폴더. 탐색기 주소창에 직접 붙여넣기.)
메모장으로 열어 **내용 전체 복사** (`<?xml` 로 시작).

### 2. GitHub Secrets 등록

레포 → `Settings` → `Secrets and variables` → `Actions` → `New repository secret` 세 번:

| Name | Value |
|---|---|
| `UNITY_LICENSE` | 위에서 복사한 `.ulf` 내용 전체 |
| `UNITY_EMAIL` | Unity 계정 이메일 |
| `UNITY_PASSWORD` | Unity 계정 비밀번호 |

### 3. Pages 켜기

레포 → `Settings` → `Pages` → `Build and deployment` → `Source` 를 **GitHub Actions** 로.

### 4. 빌드 실행

레포 → `Actions` → `WebGL Demo` → `Run workflow` → `Run workflow`.
**첫 빌드는 15~25분** 걸린다 (Unity 도커 이미지 다운로드 포함). 이후 push 마다 자동 실행.

초록 체크가 뜨면 위 주소에서 플레이 가능. 브라우저 캐시 때문에 안 바뀌면 `Ctrl+F5`.

## 웹 데모에서만 다른 동작

| 항목 | exe (본 실험) | 웹 데모 |
|---|---|---|
| A/B 선택 | 빌드 시 고정, 타이틀 우하단 표시만 | 타이틀 좌하단에 `A` `B` 버튼 (기본 A) |
| 그만하기 / 포기 / 클리어 후 종료 | 프로그램 종료 | 타이틀 화면으로 복귀 |
| 로그 CSV | exe 옆 `logs/` | 브라우저 IndexedDB (꺼내기 어려움 — 데모에선 무시) |
| 창 크기 | 1280×720 고정 | 캔버스 1280×720, 브라우저 확대/축소는 못 막음 |

코드상 이 차이는 전부 `#if UNITY_WEBGL` 안에만 있어서 **exe 빌드에는 영향이 없다.**

## 실패했을 때

`Actions` 탭에서 빨간 X 클릭 → 실패한 단계 로그의 마지막 30줄 정도를 복사해서 보내기. 자주 나는 것:

| 로그에 보이는 문구 | 원인 | 대처 |
|---|---|---|
| `License activation failed` / `No valid license` | Secrets 오타, 또는 `.ulf` 내용 일부만 복사 | 세 Secret 다시 등록. `.ulf` 는 첫 줄 `<?xml` 부터 끝 `</root>` 까지 |
| `Unable to find image 'unityci/editor:...'` | 해당 Unity 버전 이미지 없음 | `ProjectSettings/ProjectVersion.txt` 의 버전을 보고 → 원격 수정 |
| 컴파일 에러 (`error CS....`) | 코드 문제 | 그 줄 복사해서 보내기 |
| `Pages` 배포 단계에서 404 / 권한 오류 | 3번(Source = GitHub Actions) 안 함 | 설정 후 `Run workflow` 다시 |
| 사이트는 뜨는데 로딩 바에서 멈춤 | 압축 포맷 헤더 문제 | 이미 압축 끔으로 설정돼 있음. 그래도 나면 브라우저 콘솔(F12) 빨간 줄 복사 |
