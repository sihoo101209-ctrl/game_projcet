## 확정 사양 한눈에

### 플레이어
이동 5유닛/초 · HP 120 · 피격 10 · 무적 0.5초
마우스 꾹 누르기 자동 연사 · 0.25초 → 무기 획득 후 0.15초
투사체 15유닛/초 · 벽이나 적 1체에 닿으면 소멸

### 적 (총 20 · 최종 보스 별도)
근접 12 · 원거리 6 · 탱커 1 · 준보스 1

| | 근접 | 원거리 | 탱커 |
|---|---|---|---|
| HP | 2발 | 2발 | 6발 |
| 속도 | 3.5 | 2.5 | 2 |
| 데미지 | 10 | 10 | 20 |

### 준보스(방 7) / 보스(방 8)
같은 프리팹, 변수만 분기

| | 준보스 | 보스 |
|---|---|---|
| HP | 12발 | 24발 |
| 패턴 | 돌진만 | 8유닛 초과 돌진 / 이하 샷건(60도 5발, 사거리 8) |
| 쿨타임 | 3초 | 3초 |
| 접촉 | 상시 15 | 상시 20 |

### 방 규칙
- 입장 시 문 잠김 → 적 전멸 시 개방 (시작방만 예외)
- 잠김 빨강 / 열림 초록
- **클리어한 방은 재진입해도 적이 안 나옴**
- 보상은 전멸 순간 자동 획득 + 상단 알림 1.5초

### 보상 (방 3·5·7, A/B 동일)
체력회복 +60 · 무기 연사 0.25 → 0.15초

### UI
- 좌상단: 방 번호 + HP 바
- 상단 중앙: 보스 체력 바 (고정)
- 적 머리 위: 피격 시 체력 바 → 1초 후 사라짐
- **그만하기 버튼 없음**
- ESC 메뉴: 계속하기 / 맵 보기 / 조작법 / 그만하기
- 사망 화면: 다시 시도 / 포기하기 (확인 없음)

### 맵 (ESC 메뉴 안에만)
- 클리어한 방 = 채워짐 + 번호
- 인접 미탐색 방 = 점선 + `?`
- 그 너머 = 안 그림
- **일방통행 방향 표시 금지**
- 열 때마다 `RecordMapView()` 호출

### 기술
창모드 1280×720 고정 · 60fps 상한 · 모든 이동 `Time.deltaTime` 기반

## 절대 놓치면 안 되는 것 5개

1. 플레이어 프리팹 **Tag = `Player`** — 없으면 방 진입이 기록 안 됨
2. 빌드 직전 **Map Version 확인** — 안 바꾸면 두 빌드 다 A로 찍혀 20명 전부 무효
3. **게임 화면에 미니맵 금지** — ESC 메뉴 안에만
4. **맵에 일방통행 방향 표시 금지** — 되돌림 복도가 함정으로 기능 못 함
5. **A/B 총 적 수 각각 20** — 콘솔에 출력해서 눈으로 확인

## 오늘 밤 순서

1. 파일 7개 배치 → Claude Code 실행
2. "CLAUDE.md 읽고 1번 작업부터 시작해줘"
3. 코드 나오는 동안 프리팹 병렬로 제작
4. 단계마다 직접 Play 눌러 확인, 에러는 콘솔 그대로 붙여넣기
5. A 빌드 → B 빌드 → 각각 한 판씩 돌려 CSV 검증 (`릴리즈_방법.md` 참고)

로그는 빌드에서 **exe 옆 `logs` 폴더**에 저장된다. 에디터에서는 persistentDataPath.

**컷 라인**: A 버전이 검증까지 끝나면 오늘은 성공. B는 A 복제라서 다음에 빨라. 막히면 저장하고 끊을 것.
