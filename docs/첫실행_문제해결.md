# 첫 실행 문제해결 — 증상별 대처

Unity 에디터에서 직접 돌려보지 않고 작성한 코드다. 첫 Play 에서 아래 중 하나가 날 수 있다.
**콘솔의 빨간 줄을 통째로 복사해서 보내면** 원격에서 고쳐 푸시한다 → 노트북에서 `git pull`.

빨간 에러가 하나라도 있으면 Play 버튼이 안 눌린다 (컴파일 에러). 노란 경고는 무시해도 된다.

---

## A. 프로젝트를 열 때

| 증상 | 원인 | 대처 |
|---|---|---|
| Hub 에서 "2022.3.20f1 이 설치되어 있지 않음" | `ProjectVersion.txt` 의 버전과 설치 버전이 다름 | 설치된 2022.3.x 선택해서 열기. 업그레이드 확인창은 `Continue` |
| "Enter Safe Mode?" 창 | 컴파일 에러가 있음 | `Ignore` 누르고 콘솔 에러 복사해서 보내기 |
| 콘솔에 `Library/PackageCache` 어쩌구 경고 다수 | 첫 패키지 다운로드 | 무시. 1~3분 기다림 |
| `The type or namespace name 'TMPro' could not be found` | TMP 를 쓰는 파일이 Assets 안에 있음 | `Assets/Scripts` 에 `SessionStartUI.cs` `VersionLabel.cs` 가 있으면 삭제 (현재 브랜치엔 없어야 정상) |
| `error CS0246 ... 'InputField'` / `'Text'` | uGUI 패키지 누락 | `Window → Package Manager → Unity Registry → Unity UI` 설치 |

## B. Play 를 눌렀을 때

| 증상 | 원인 | 대처 |
|---|---|---|
| 화면이 검고 아무것도 없음 | 카메라 없음 / MapBuilder 안 붙음 | Hierarchy 에 `Main Camera` 가 실행 중 생겼는지 확인. `Game` 씬의 `MapBuilder` 오브젝트에 스크립트가 붙어 있는지(Inspector 에 "Missing Script" 면 `.meta` GUID 문제 → 컴포넌트 제거 후 `Add Component → MapBuilder` 다시) |
| `[맵] Resources/map_A.json 을 찾을 수 없음` | Resources 폴더 이름/위치 | `Assets/Resources/map_A.json` 경로 정확한지 확인 (폴더명 R 대문자) |
| `[맵] map_A.json 파싱 실패` | JSON 깨짐 | 파일을 메모장으로 열어 마지막 `}` 까지 있는지 확인. 브랜치 원본으로 되돌리기: `git checkout -- Assets/Resources` |
| `[맵 A] 총 적 수 = N — 30이 아님!` | JSON 수정으로 적 수가 틀어짐 | 위 명령으로 원본 복구. **이 상태로 테스트하면 데이터 무효** |
| 한글이 전부 네모(□) | 맑은 고딕을 못 찾음 | 콘솔에 `[폰트]` 에러가 있을 것. Windows 면 거의 안 남. Mac 이면 정상 현상 — Windows 에서 빌드 |
| 텍스트가 분홍색 | 셰이더 문제 (TMP 아님, 이 프로젝트는 TMP 안 씀) | 2D 템플릿이 아닌 URP/HDRP 프로젝트로 열었을 때. 새로 만들지 말고 이 저장소 폴더를 그대로 열었는지 확인 |
| 방은 보이는데 플레이어(하늘색 네모)가 없음 | 플레이어 스폰 실패 | 콘솔 `[맵] 시작방(tutorial)이 없음` 확인 → JSON 원본 복구 |
| 플레이어가 안 움직임 | Input 설정 | `Edit → Project Settings → Player → Active Input Handling` 이 `Input Manager (Old)` 또는 `Both` 인지 |
| 마우스를 눌러도 총알이 안 나감 | 위와 동일 / 카메라 없음 | 위 두 항목 확인 |
| 총알이 벽을 뚫고 계속 감 | 키네마틱 접촉 설정 | 코드에서 `useFullKinematicContacts` 를 켜두었음. 그래도 뚫으면 `Edit → Project Settings → Physics 2D → Queries Hit Triggers` 확인 후 보고 |
| 적이 안 나옴 / 문이 안 잠김 | 방 트리거 미작동 | 플레이어 오브젝트의 `Tag` 가 `Player` 인지 (코드가 자동 지정하지만 프리팹을 꽂았다면 프리팹 태그 확인) |
| 적이 플레이어를 통과하고 데미지 없음 | 콜라이더가 트리거로 설정됨 | 프리팹을 꽂았다면 `Is Trigger` 해제. 자동 생성이면 발생 안 함 |
| 적을 다 죽였는데 문이 빨간색 그대로 | 적이 하나 남음 (화면 밖/벽 안) | 방 구석까지 확인. 재현되면 방 번호와 함께 보고 |
| 문이 초록인데 못 지나감 | 일방통행 문의 반대편 | B 의 방 3↔6, 방 2↔102 는 한 방향만 통과됨 (의도). 다른 문이면 보고 |
| ESC 눌러도 메뉴 안 뜸 | 사망 화면/클리어 화면 중 | 정상. 그 외면 보고 |
| 버튼을 눌러도 반응 없음 | EventSystem 없음 | Hierarchy 에 `EventSystem` 이 생겼는지. 없으면 `GameObject → UI → Event System` 수동 추가 후 보고 |
| 죽었는데 사망 화면 안 뜸 | DeathScreen 초기화 실패 | 콘솔 에러 복사 |
| 창이 전체화면으로 뜸 (빌드) | Player 설정 | `Project Settings → Player → Resolution → Fullscreen Mode = Windowed`, 1280×720, `Resizable Window` 해제 |

## C. 로그가 안 남을 때

| 증상 | 대처 |
|---|---|
| 에디터에서 `summary.csv` 가 어디 있는지 모름 | 콘솔 `[로그] 저장 완료 → 경로` 에 나옴. 보통 `C:\Users\이름\AppData\LocalLow\LevelLayoutStudy\game_projcet` |
| 빌드에서 `logs` 폴더가 없음 | 게임을 **끝까지**(클리어 또는 포기) 해야 저장된다. 창 X 로 닫아도 포기로 기록됨 |
| `버전` 열이 전부 A | B 빌드 전에 Start 씬 `GameLogger → Map Version` 을 B 로 안 바꿈. **B 빌드 다시** |
| 기기 0 / 참가자 0 행이 섞여 있음 | Game 씬을 바로 Play 한 테스트 기록. 분석 때 제외 |

## D. 바로 확인해볼 것 (플레이 체크리스트)

1. 시작방 바닥에 안내 문구 4줄이 보인다
2. 방 1 에 들어가면 문이 빨갛게 되고 콘솔에 `[로그] 타이머 시작` 이 뜬다
3. 적 2마리 처치 → 문 초록
4. 방 3 클리어 → 상단에 `체력 회복  +60`
5. ESC → 맵 보기 → 클리어한 방은 번호, 옆 방은 `?`, 그 너머는 안 보임
6. 일부러 죽기 → 사망 화면 → 다시 시도 → 같은 방 입구에서 부활, 적 리셋
7. 방 8 보스 처치 → 클리어 화면 → 종료 → CSV 확인

## E. 원격 수정 왕복

```
(노트북) 에러 복사 → 보내기
(원격)   수정 → 같은 브랜치 push
(노트북) git pull   ← Unity 창으로 돌아가면 자동 재컴파일
```

`git pull` 이 "local changes would be overwritten" 으로 거부되면 노트북에서 뭔가 고친 것.
`git stash` → `git pull` → `git stash pop` 순서로.
